# Elegant TOC - 优雅的 WordPress 文章目录插件

一个现代、美观、功能完善的 WordPress 文章目录插件，完全免费且无任何功能限制。

## ✨ 功能特性

### 核心功能
- 🎨 **优雅的设计** - 采用现代深色调设计，支持明暗主题自动切换
- 📱 **完全响应式** - 在各种设备上都能完美显示
- 🎯 **智能高亮** - 根据滚动位置自动高亮当前阅读的标题
- 🔄 **平滑滚动** - 点击目录项时平滑滚动到对应位置
- 💾 **状态记忆** - 记住目录的折叠/展开状态
- 🎛️ **灵活配置** - 支持自定义标题层级、最少标题数等，并自动适配侧边栏/内联布局

### 设计亮点
- 渐变背景和精致阴影效果
- 流畅的动画过渡
- 优雅的交互反馈
- 完善的无障碍支持
- 自定义滚动条样式

## 📦 安装方法

### 方法一：通过 WordPress 后台安装

1. 将整个插件文件夹上传到 `/wp-content/plugins/` 目录
2. 在 WordPress 后台的"插件"页面激活 "Elegant TOC"
3. 前往"设置" → "Elegant TOC"进行配置

### 方法二：直接上传

1. 下载插件压缩包
2. 在 WordPress 后台，前往"插件" → "安装插件" → "上传插件"
3. 选择下载的压缩包并安装
4. 激活插件

## ⚙️ 配置选项

### 基本设置

- **启用目录** - 控制是否在文章中显示目录
- **最少标题数** - 设置显示目录所需的最少标题数量（默认 3 个）

### 布局行为

- **桌面端**：当浏览器宽度 ≥ 1024px 且正文左侧有足够空白时，目录以**左侧悬浮侧边栏**形式显示，紧贴正文容器左侧；滚动时保持固定，离开正文区域后自动隐藏
- **移动端 / 空间不足**：左下角显示一个**目录触发按钮（三横图标）**，点击后以底部浮层面板形式展开目录；点击链接或关闭按钮后恢复为悬浮按钮
- 面板宽度在手机端自适应，平板端最大 480px，打开/关闭带有过渡动画

### 标题层级

可以选择包含在目录中的标题层级：
- H2（主标题）
- H3（二级标题）
- H4（三级标题）
- H5（四级标题）
- H6（五级标题）

## 🎨 设计系统

### 颜色方案

插件使用精心设计的色阶系统：

**深色主题**
- 背景层级：从 `#05070C` 到 `#1E2636` 的五级灰阶
- 强调色：天蓝色 `#38BDF8`
- 辅助色：深青色 `#1E3A52`

**浅色主题**
- 自动适配系统浅色模式
- 优化的对比度和可读性

### 视觉特性

- **圆角设计** - 统一的圆角半径系统（8px/12px/16px）
- **间距系统** - 基于 rem 的弹性间距
- **流体字体** - 使用 clamp() 实现响应式字体大小
- **渐变背景** - 135度角的双色渐变

## 🔧 技术特性

### 前端技术

- 纯 JavaScript（无依赖）
- CSS Grid 和 Flexbox 布局
- CSS 自定义属性（CSS Variables）
- Intersection Observer API（用于性能优化的滚动监听）
- 平滑滚动 API
- LocalStorage（状态持久化）

### 性能优化

- 节流函数防止滚动事件过度触发
- Intersection Observer 替代传统滚动监听
- CSS 动画使用 GPU 加速的 transform
- 条件加载（仅在文章页面加载资源）

### 兼容性

- WordPress 5.0+
- PHP 7.0+
- 现代浏览器（Chrome、Firefox、Safari、Edge）
- IE11 降级支持

## 📖 使用示例

### 自动模式

插件激活后，会自动在所有满足条件的文章中显示目录，无需任何代码。

### 短代码支持

在任意文章/页面内容中插入短代码，即可在指定位置渲染目录：

```
[elegant_toc]
```

使用短代码时，插件会在短代码所在位置渲染目录。

### 单篇文章禁用

方法 1：在文章编辑器右侧的 **Elegant TOC** 元数据框中勾选“在此文章/页面中禁用目录”。

方法 2：通过自定义字段禁用：
- 字段名：`disable_toc`
- 字段值：`1`
